# 🛠️ Build Android APK

## Requirements

Install:

- Node.js
- npm
- Android Studio

---

## 1. Install dependencies

```bash
npm install
```

---

## 2. Add Android platform

```bash
npm install @capacitor/android

npx cap add android
```

---

## 3. Synchronize files

```bash
npx cap sync
```

---

## 4. Open Android Studio

```bash
npx cap open android
```

---

## 5. Build APK

Inside Android Studio:

```
Build
 └── Build Bundle(s) / APK(s)
      └── Build APK(s)
```

Your installable APK will be generated automatically.
